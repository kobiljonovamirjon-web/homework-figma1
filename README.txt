POSITIVUS — учебный сайт по мотивам видео

Файлы:
- index.html — структура сайта
- style.css — оформление и адаптивность
- script.js — мобильное меню, аккордеон, слайдер отзывов и демо-формы

Как открыть:
1. Распакуйте ZIP.
2. Откройте папку.
3. Дважды нажмите index.html или откройте его в VS Code и используйте Live Server.

Важно:
Это самостоятельная учебная реализация по мотивам дизайна из видео, а не исходный файл Figma.
Формы демонстрационные: они показывают подтверждение в браузере, но не отправляют сообщения на сервер.

Видео-референсы:
Папка assets содержит скриншоты, извлечённые из предоставленного видео. Иллюстрация на первом экране использует фрагмент оригинального дизайна из видео. Скриншоты включены как референсы для дальнейшей точной сборки.
